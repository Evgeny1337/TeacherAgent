## Качество генерации (переход)

Сейчас: один проход `deepseek-flash` → полный `LessonPlan`.  
Цель: выше педагогическое качество и меньше «кривых» планов **без** обязательной локальной модели в `.app`.  
Отдельных публичных моделей «только для уроков» под нашу схему почти нет — упор на сильную общую модель + эталоны + проверку.

Порядок внедрения (ROI сверху вниз):

- [ ] **Сильнее модель на generate**  
  `generate_plan` / full revise → `deepseek-chat` (или аналог сильнее flash).  
  Brief + revise-router (+ позже critic) оставить на flash / дешёвой модели.  
  В `llm.py`: конфиг model / `base_url` (env), не хардкод одного имени.

- [ ] **Few-shot эталоны**  
  1–2 «хороших» `LessonPlan` JSON (реальные утверждённые уроки) в промпт generate  
  или отдельный файл `examples/` + подстановка в user/system.  
  Сильнее любых edu-файнтюнов для нашей схемы.

- [ ] **Critic-pass после generate**  
  После первого `LessonPlan`, до Word: короткий вызов «проверь план»  
  (timing ≈ duration, aim↔stages, handouts↔procedure, пустые/дубли stages).  
  Ответ: список замечаний **или** сразу `LessonPlanPatch` → merge (переиспользовать revise-patch).  
  Без текста учителя; полный rewrite не делать.  
  Опционально тот же critic перед записью после revise.

- [ ] **Мягкий brief / enum’ы** *(см. Pending выше)*  
  Нормализация `cefr_level` / `lesson_type` / `readiness` — меньше мусора на входе в plan.

- [ ] **RAG по банку уроков** *(после накопления утверждённых)*  
  По brief (уровень, тема, focus) доставать 1–3 похожих эталона → в контекст generate.  
  Не блокер пилота; имеет смысл когда есть 20+ хороших планов.

- [ ] **Локальная модель — только fallback (Mac M3)**  
  Не основной путь качества и не тащить 10+ GB в `.app` на старте.  
  Опция офлайн: Ollama / MLX + OpenAI-совместимый `base_url` (`127.0.0.1`).  
  Тихо на ноуте: примерно ≤8–14B Q4; слабее cloud mid-tier, греет при генерации.  
  UI: предупреждение «медленнее / проще»; по умолчанию облако.  
  Спецмодели «для уроков» не искать как серебряную пулю.

Целевой пайплайн после перехода:

```
brief → generate (strong) [+ few-shot / RAG]
     → critic → patch/merge (если нужно)
     → Word
     → (учитель) revise router → patch | full
     → optional critic → Word
```
